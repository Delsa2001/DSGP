Conversion FAQ

                

                    

                        
Is my data safe with CleanConvert?

                        
Yes. CleanConvert is a client-side only tool. This means all conversion logic happens inside your browser's memory. We do not have a backend server, and your data is never uploaded, stored, or shared.

                    

                    

                        
How do I flatten nested JSON objects for Excel?

                        
Simply paste your nested JSON. Our tool automatically detects the depth and flattens it into dot-notation headers (e.g., user.address.zipcode), making it perfectly readable for CSV and Excel formats.

                    

                    

                        
Can I rename columns before exporting?

                        
Absolutely. In the Live Preview table, double-click any column header to rename it. The exported file will reflect your custom column names.

                    

                    

                        
How does CleanConvert handle special characters and encoding?

                        
We use UTF-8 encoding by default, which supports almost all global languages and special characters. Whether you're converting emojis, accented letters, or non-Latin scripts, your data remains intact during the process.

                    

                    

                        
What happens if my JSON has missing values or null fields?

                        
CleanConvert handles sparse data gracefully. If a field is missing in some JSON objects, it will simply appear as an empty cell in the CSV or Markdown output. You can also use the "Drop Nulls" tool in our cleaning toolbar to remove these fields entirely.

                    

                    

                        
Is there a limit to the size of data I can convert in the browser?

                        
Since processing happens locally, the limit depends on your computer's RAM. Most modern browsers can comfortably handle files up to 50MB–100MB. For extremely large datasets, we recommend converting in smaller batches to ensure smooth performance.

                    

                    

                        
How do I know if my JSON or XML input is valid?

                        
Our tool features real-time validation. If your input is malformed, an error box will appear below the input area with details about the syntax error (e.g., a missing comma or unclosed tag), helping you fix it instantly.

                    

                    

                        
Can I convert YAML to JSON for Kubernetes or Docker?

                        
Yes. CleanConvert is ideal for DevOps tasks. You can paste complex YAML configurations and instantly get a valid JSON object or CSV, making it easier to audit or transform configuration files.

                    

                    

                        
How are Markdown tables formatted?

                        
Our Markdown output follows the GitHub Flavored Markdown (GFM) standard. It includes a header row followed by a separator line (`|---|`), ensuring your data renders perfectly in GitHub READMEs, documentation, or static site generators like Jekyll and Hugo.

                    

                    

                        
Can I generate SQL scripts for database migrations?

                        
Yes. The SQL export option generates `INSERT INTO` statements for your data. It automatically handles string escaping and NULL values, making it perfect for seeding MySQL, PostgreSQL, or SQLite databases.

                    

                    

                        
What is the difference between CSV and TSV export?

                        
CSV (Comma Separated Values) is the standard for Excel and general use. TSV (Tab Separated Values) is often preferred in data science and programming because it handles commas within cell data more naturally without needing complex quoting.

                    

                    

                        
Can I paste a table from a website or a Markdown file?

                        
Yes! CleanConvert now supports **HTML and Markdown tables as input**. Just copy the table from a website or a `.md` file and paste it into the input area. Our engine will automatically detect the format and convert it into JSON, CSV, or any other supported format.
